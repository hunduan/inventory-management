# 进销存管理系统 — 项目计划

**日期**: 2026-05-26 | **状态**: 开发中

---

## 一、项目概述

进销存管理系统（InOut）— 多租户库存管理系统。Web 管理后台 + 微信小程序。

| 层 | 技术 |
|---|------|
| 前端 | Taro 4 + React 18 + TypeScript + Less |
| 后端 | NestJS 11 + TypeScript + Prisma 7 + PostgreSQL |
| 认证 | JWT (passport-jwt) |
| 状态管理 | Zustand 4 |

## 四、设计约定

### CSS 变量
```css
--primary: #0f766e    --bg: #f5f5f4         --surface: #ffffff
--text: #1c1917       --text-secondary: #78716c   --text-muted: #a8a29e
--border: #e7e5e4     --success: #16a34a    --warning: #d97706    --danger: #dc2626
```

### Web 端布局
- 侧栏（72px，默认收起）：中文单字导航（进/品/进/销/存/表/设）
- 内容区：白卡 + 浅灰底，固定百分比列表格
- 采购/销售表：单号(18%) + 供应商/客户(16%) + 仓库(12%) + 金额(12%) + 状态(10%) + 时间(14%) + 操作(18%)

### 小程序布局
- 底部自定义 tabBar：首/品/单/存（青绿色选中态）
- 各页面独立 teal 色头部栏
- 白卡 + 浅灰底

## 五、开发命令

```bash
# 后端
cd backend && npm run build && npm run start

# Web 端
cd client && npm run build:h5
# 静态服务: cd dist/h5 && python -m http.server 8080

# 小程序
cd client && npm run build:weapp
# WeChat DevTools 打开 client/ 目录
```
