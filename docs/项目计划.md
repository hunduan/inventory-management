**日期**: 2026-05-30 | **状态**: 开发中

## 一、项目概述

进销存管理系统（InOut）— 多租户库存管理系统。两个前端共享一套 NestJS API。

| 层 | 技术 |
|---|------|
| Web 前端 | Vite 8 + React 19 + Ant Design 6 + React Router 7 + Zustand 5 |
| 小程序前端 | Taro 4 + React 18 + TypeScript + Less（`client/` 目录） |
| 后端 | NestJS 11 + TypeScript + Prisma 7 + PostgreSQL |
| 认证 | JWT (passport-jwt) |
| 状态管理（Web） | Zustand 5 |

## 七、数据流说明

### 库存预警机制
- 无单独的预警表，也无定时任务
- 实时查询 `Inventory` 表 `quantity <= threshold`
- 默认阈值 10，可通过 `threshold` 参数自定义
- 返回分页结果，按库存升序排列（库存最少的排最前）

### 库存日志关联单据流程
1. 查询 `InventoryLog` 表获取某商品的变动记录
2. 按 `refType` 将 `refId` 分组（PURCHASE_ORDER / SALE_ORDER / TRANSFER / STOCKTAKE）
3. 批量查询对应表获取订单详情（单号、对方名称、状态、金额）
4. 注入到每行日志的 `refOrder` 字段返回前端
5. 前端显示类型标签 + 单号 + 对方名称，并提供"查看详情"按钮跳转
