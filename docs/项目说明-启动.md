# 项目说明与本地启动指南

## 一、项目概述
- 名称：进销存管理系统（InOut）
- 功能：多租户的库存、采购、销售、报表、用户与权限管理
- 目录：后端（NestJS + Prisma）、前端（Taro4 + React + TypeScript）和设计文档

## 二、技术栈
- 后端：NestJS 11、TypeScript、Prisma 7、PostgreSQL
- 前端：Taro 4（H5 + Weapp）、React 18、TypeScript、Less / Tailwind
- 其他：Passport/JWT、Swagger、Prisma 工具链

## 三、主要代码位置
- 后端入口：`backend/src/main.ts`
- Prisma 配置：`backend/prisma.config.ts`，模式文件：`backend/prisma/schema.prisma`
- 前端入口与页面：`client/src`，Taro 配置：`client/config/index.ts`
- 前端构建产物：`client/dist/h5`（H5） 与 `client/dist/weapp`（小程序）

## 四、本地运行前置条件
- 安装：Node.js（>=18 推荐）、npm、PostgreSQL
- 环境变量：需设置 `DATABASE_URL`（Postgres 连接字符串）
- （可选）全局静态服务器：`serve` 或 `http-server`，用于预览 `client/dist/h5`

## 五、后端（开发）启动
1. 进入后端目录：
```powershell
cd backend
npm install
```
2. 设置数据库连接（PowerShell 示例）：
```powershell
$env:DATABASE_URL="postgresql://user:pass@localhost:5432/inout_dev?schema=public"
```
3. 生成 Prisma 客户端并应用迁移（仅在需要时执行）：
```bash
npx prisma generate
npx prisma migrate dev
npm run seed   # 若存在 seed 脚本，初始化演示数据
```
4. 启动开发模式（实时重启）：
```bash
npm run start:dev
```
- 默认监听端口：`3000`
- Swagger UI：`http://localhost:3000/api/docs`

## 六、后端（生产）构建与运行
```bash
cd backend
npm install
npm run build
# 设置好环境变量后
npm run start:prod
```

## 七、前端（H5）开发与构建
1. 进入前端目录：
```bash
cd client
npm install
```
2. 开发（H5 热重载）：
```bash
npm run dev:h5
# 打开 taro 输出的开发地址（常见为 http://localhost:10086），或终端显示的 URL
```
3. 生产构建（生成静态文件）：
```bash
npm run build:h5
# 构建结果位于 client/dist/h5
```
4. 预览生产包（在项目根运行静态服务器）：
```bash
# 在 repo 根或任意位置运行：
# 使用 Python 内置服务器（跨平台）
cd client/dist/h5
python -m http.server 8080
# 或使用 npx http-server
npx http-server . -p 8080
```
- 示例已在本机以 `http://localhost:8080` 提供预览。

## 八、前端与后端交互
- 前端配置的 API 基础地址（见 `client/config/index.ts`）：`http://localhost:3000/api`。
- 若后端端口或主机改变，请同步修改该配置或在构建时注入环境变量。

## 九、排查登录失败的快速检查清单
1. 后端是否已启动并监听 3000（可访问 `http://localhost:3000/api/docs`）。
2. 前端是否指向正确的 API 地址（`client/config/index.ts` 中 `API_BASE_URL`）。
3. 后端日志是否有认证失败或数据库连接错误（查看后端终端输出）。
4. 数据库是否可达且已完成迁移/有 seed 数据（确认用户存在）。
